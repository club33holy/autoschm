Configuration

Open the in-game settings via ModMenu or type /autoschem config.

Config Options config.json
• buildSpeed: Blocks placed per tick (default: 2, range: 1-10).
• baritoneIntegration: Uses Baritone pathfinding to walk around and place out-of-reach blocks (default: true).
• autoInventorySwap: Automatically restocks matching blocks from inventory or hotbar (default: true).
• renderGhostLayerOnly: Only renders the current active layer (default: false).

Commands & Default Keybinds

Control Auto Schem with intuitive commands or configurable keys:

/autoschem load <file>
Loads a schematic file from your local folder.
/autoschem start
Begins placing the loaded schematic.
/autoschem pause
Pauses current placement. Type /autoschem resume to continue.
/autoschem speed <1-10>
Adjusts placement speed and blocks per tick.

Default Keyboard Shortcuts:
• B: Start / Pause Auto Placement
• M: Open Schematic Manager GUI
• Page Up / Down: Layer slicer up / down
• H: Toggle Holographic Wireframe

Troubleshooting

Error: Game crashes on startup
Fix: Ensure both Fabric API and Baritone for Minecraft 1.21.11 are installed in your mods directory.
Issue: Player not moving to place out-of-reach blocks
Fix: Verify that Baritone is enabled in /autoschem config so the mod can pathfind to higher blocks.
